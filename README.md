# 团影视 (TuanYingShi)

聚合追番 · 在线播放 · 离线下载 的安卓影视 App。

> ⚠️ 本项目**不开源**，本仓库仅用于**应用下载与使用**。
> 源代码仓库：[fs529/tuan-ying-shi-app](https://gitee.com/fs529/tuan-ying-shi-app)

---

## 📥 下载安装

- **最新版本**：v0.3.0
- **下载地址**：[`app-debug.apk`](app-debug.apk)（点击文件后点「下载」即可保存到手机安装）

> 安装前请在系统设置中允许「安装未知来源应用」。

---

## ✨ 功能简介

- 热播番剧推荐、分类浏览（番剧 / 电影 / 国漫等）
- 在线播放：支持倍速、选集、画面适应、弹幕
- 离线下载，无网也能看
- 排期表 / 排行榜，追番不漏更
- 开屏封面自定义（内置 / 链接 / 相册图片）
- 支持在文件管理器中用本 App 直接打开本地视频

---

## 📖 使用说明

1. 下载并安装 APK；
2. 首次启动联网加载内容（资源来自第三方公开站点，仅供学习交流）；
3. 在「我的 → 关于」中可查看更新日志、提交反馈、前往项目主页。
